## The owner's standing rules (George)

- Finished work ships by itself: open a non-draft PR, let CI and the auto-merge
  sweep merge it, let the deploy run, then give him the live URL. Never merge by
  hand. Never ask him about git or branches; ask only about the product, and
  offer options to pick from.
- When he must do something, give a full clickable URL and exact taps.
- One shape per kind (the fleet rule in bitbaum/fleet AGENTS.md). Every chat is
  built on `@bitbaum/chatkit`. Packages by default. Search goes through
  `@bitbaum/searchkit`. Charts go through `@bitbaum/chartkit`.
- Nothing made up. Every fact needs a source URL actually opened, a literal
  quote and a date, or the row does not exist. Wikipedia is a pointer, not
  evidence.
- Bitcoin orange only for Bitcoin and top-of-funnel actions. No paid APIs
  (bring-your-own-key is optional). No model identifier in anything pushed to a
  repository.
- Cheaper models must be able to fill data: build systems first, then data.
